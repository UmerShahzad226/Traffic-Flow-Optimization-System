# Contributing Guidelines

## Standards
- Do not remove default comments.
- Do not add newlines or extra blank lines.
- Keep constructors at the top of each class, then getters/setters below, and member functions at the bottom.
- Keep the existing syntax style.
- Avoid adding extra functions unless necessary.
- Add concise comments in the style //comment where needed.

## Workflow
- Keep changes scoped and consistent with existing file structure.
- Maintain behavior unless a change is required to fix a bug.
